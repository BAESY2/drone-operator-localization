# Data

No country-locked datasets. Runtime uses worldwide public APIs:

| Use | API | Coverage |
|-----|-----|----------|
| Buildings / roads / masts | OpenStreetMap Overpass | Global (density varies) |
| Geocode / reverse | Nominatim | Global |
| Elevation | Open-Meteo, OpenTopoData SRTM | Global |
| Imagery | Esri, NASA GIBS, OSM, OpenTopoMap | Global |

Local cache: `.cache/geo/` (gitignored).
